Finding one

Expiry is not currency. The second run refuses a token that is still cryptographically valid and still inside its validity window, because a signed event superseded the judgment behind it. A verifier that checks exp and stops accepts that request.

Finding two

A level is eligibility, never permission. Clearing the trust bar buys the agent the right to be considered. Route, budget, mission, and local policy still decide, and they decide last.

What this does not show

  • Runtime measurements are fixture values, not a live enclave quote.
  • The ATF profile version is a placeholder until it is fixed.
  • AAuth carriage is modelled as JSON, not a real token.
  • Issuer and verifier ran on one machine, so this is an integration proposal, not an interop result.

Check it without trusting the page

The run exports a bundle carrying the records, the appraisals, the signed event, and the public keys. Nothing in it needs us to be online.

python demo/tools/stage.py --export bundle/
python demo/tools/verify_chain.py --bundle bundle/

Exit code 0 means every case matched its expected outcome. Change one byte in any record and the first run turns into deny / invalid_trace_signature.
